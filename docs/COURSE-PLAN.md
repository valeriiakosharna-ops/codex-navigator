# Codex Navigator: course plan (v2.0)

The course is built on **OpenAI's official Codex training**: the OpenAI Academy learning paths
(each ends with an assessment and an Accredible badge), the ChatGPT/Codex docs, OpenAI's
YouTube channel and the OpenAI Cookbook. Our pages add the "why", use cases, practice labs
and quizzes. They don't copy OpenAI's text.

Source: the *Codex OpenAI* tab of *Tech Edu - GenAI Dashboard.xlsx*. The plan follows its
five modules and eleven units, extends them where the official training covers more, and
adds an elective module built from the agent courses in the same tab.

**Audience labels.** Each topic is marked for one of three groups: **Everyone**, **Technical specialists** or **Non-technical specialists**. No job titles are listed.

**Badges and grades.** Six pages are *badge checkpoints*. The learner finishes the Academy
learning path (course plus an assessment passed with **≥ 80%**), receives an Accredible badge
link by email, and pastes it into the checkpoint. The page checks the badge against
Accredible's public record (issuer OpenAI, the right course, not revoked or expired, issued to
the learner's name in Moodle) and sends **100/100** to Moodle on its own.
Every other topic is graded by its own quiz or lab.

## Changes from the source spreadsheet

- **Expanded:** 1.1 (surfaces), 1.4 (context and done criteria), 4.2 (skills, plugins, hooks) and 5.4 (multi-team coordination). These are the cores of the three Academy Codex paths, and the spreadsheet had no unit for them.
- **Unit 11 split in two**: CI/CD and enterprise administration, which are different skills and are assessed differently.
- **Labs** added after modules 1, 2, 3 and 5. They are deterministic, with no AI, and test judgement rather than tool skills.
- **Badge checkpoints** for all six Academy paths mentioned in the tab. AI Foundations and Applied AI Foundations are listed as recommended prerequisites for the non-technical track, not graded.
- **Links corrected:**
  - `developers.openai.com/codex/*` now redirects to `learn.chatgpt.com/docs/*`, so the plan uses the new addresses.
  - *Cloud Environment Setup* (`environments/cloud-environment`) is now marked **Legacy**. It is replaced by [Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments).
  - *Codex Cyber Safety* is now titled **Models and Trusted Access** and is about approved access to cyber models. It stays in 5.1 as a pointer for security teams only.
  - *Mastering Codex Remote* is about steering work from the mobile app. It remains in 2.1 as optional reading.
- **Not used:** the Medium article from the spreadsheet's additional sources (not official) and the generic YouTube search link (replaced by specific OpenAI videos).
- **Enterprise Release Activation: October 2026** has no badge, so it isn't used as a checkpoint.
