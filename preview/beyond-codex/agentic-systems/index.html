Module 6 · Elective: building agentic systems and AI applications

Design and build agentic systems

Agents with clear roles, controlled tool access and reliable handoffs, tested against defined outcome and safety requirements. Confirmed with the official badge.

For technical specialists⏱ ~110 min in Academy + assessmentGraded · 1 pt

Why this matters#

Codex is an agent somebody else built for you. This course is about building your own: an application where several agents each have a role, call tools within limits, and hand work to each other without losing track of who owns what. If you've followed this course, the ideas will feel familiar: least-privilege tools, clear ownership, evidence over assurance. Now they're design decisions in your own product.

While you study, pay attention to

  • How each agent's role and tool access are defined, and how that compares with Codex's sandbox and approvals.
  • What gets passed at a handoff so ownership is preserved.
  • How the lab tests agent decisions and handoffs. That's the bridge to the next topic, evaluation.
