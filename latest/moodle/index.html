Moodle setup

One Moodle activity (External page with grades) per page. Paste the URL from the table — always the latest/ address; the page itself switches each learner to the right version.

Activity settings

  1. External page URL: the URL from the table below.
  2. URL variables: uid = User ID, cid = Course ID. On badge checkpoint pages also add name = Full name: the page compares it with the name on the badge and doesn't store it. Don't pass e-mails.
  3. Description: start with "For whom: …" from the table, so learners see in the course page which topics are theirs.
  4. Maximum grade: any value (e.g. 100). The page sends score / max, Moodle scales it.
  5. Grading method: Highest is recommended (retries never lower the grade).

Links between topics

Inside Moodle, a link from one topic to another opens the matching Moodle activity, not this website. After creating the activities, add their ids to moodle.yaml in the repository (page id → activity id from view.php?id=…). Without an entry, such links open the Moodle course page.

Which version does a learner see?

Cohorts are pinned in pins.yaml by Moodle course id (see the repository docs, docs/VERSIONING.md). Without a cohort pin, each learner stays on the version they opened first.
